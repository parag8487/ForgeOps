Criterion 16 is the only one still `pending`, and it is blocked by the environment
rather than by missing work: Fulcio needs the CI OIDC identity and Rekor is
unreachable behind a TLS-intercepting proxy on this network. Two further
workstation deviations are recorded rather than hidden:

- **`-race` on Windows.** The race detector needs a gcc-compatible C toolchain.
  The installed Visual Studio Build Tools supply `cl.exe`, which rejects the
  gcc-style flags cgo passes (`invalid numeric argument '/Werror'`). Local runs
  use `-shuffle=on` without `-race`; CI runs `-race -shuffle=on` on Linux.
- **Host port conflicts.** A host Redis service holds 6379 and the host reserves
  5432, so the live Compose evidence was captured with `REDIS_PORT=6380` and
  `POSTGRES_PORT=5433` supplied as process environment, not as a committed `.env`.
  The fresh-clone five-service selection was verified separately with no `.env`.
